The entry:

> I'm away today, so my AI is on inbox duty. It replies faster than me, charges nothing, and has never once asked for a raise.

## Run it

```sh
python3 main.py
```

This writes the entry to `$MAKEFUN_OUTPUT_DIR/entry.txt` (default `/output/entry.txt`) and prints it.
